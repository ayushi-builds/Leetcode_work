# LeetCode Interview Preparation

A Java-first workspace for practicing data structures and algorithms, documenting problem-solving patterns, and tracking steady interview-preparation progress.

## Study plan

This repository follows the [LeetCode 75 – Ace Coding Interview](https://leetcode.com/studyplan/leetcode-75/) study plan. Topic folders provide a practical organization for solutions; they are not intended to change the study plan's sequence.

## Learning objectives

- Build fluency with common data structures, algorithms, and problem-solving patterns.
- Explain the reasoning behind each solution, including its time and space complexity.
- Record mistakes, insights, and revision needs so practice leads to lasting improvement.
- Maintain a clear, consistent record of preparation that can grow with future study plans.

**Primary language:** Java

Each topic folder holds its Java problem files directly. The shared `templates/` directory contains the reusable solution format. This topic-based layout can accommodate additional study plans without requiring nested folders.

## Problem documentation

For each problem, create a Java file in the most relevant topic folder, following the `ProblemName.java` naming convention. Use [`templates/SolutionTemplate.java`](templates/SolutionTemplate.java) to record the problem name and number, URL, difficulty, topic or pattern, approach, complexities, and implementation. Add or update the matching row in [`PROGRESS.md`](PROGRESS.md).

## Progress and learning philosophy

Prioritize understanding over completion speed. Attempt problems independently, explain the approach in your own words, and record what did not work alongside what did. Mark a solution `Solved` only after you can explain and reproduce it; use `Needs Revision` to make follow-up practice visible. Revisit and improve notes as your understanding grows.
